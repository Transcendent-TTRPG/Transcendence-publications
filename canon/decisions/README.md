# Registro de decisiones canónicas

Este registro conserva hechos o límites aprobados por el creador que todavía no están
integrados al Corebook en español. Evita que una conversación, nota de diseño o archivo
histórico se convierta en una fuente de verdad informal.

## Estados

- `proposed`: idea registrada, no utilizable como canon.
- `approved`: decisión canónica provisional; puede ser consumida con su cita.
- `integrated`: ya está expresada en Publications ES; su ruta publicada pasa a ser la
  fuente primaria.
- `rejected`: se exploró y descartó; no debe volver a aparecer como hecho asentado.

Las decisiones deben ser breves, tener alcance claro y declarar qué texto publicado o
módulo necesitará actualizarse. Este registro está vacío intencionalmente hasta que se
apruebe una decisión concreta.
